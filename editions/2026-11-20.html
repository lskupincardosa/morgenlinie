Topic of the day: Best of the week

Critical, patches out. Calif, Qualys

Java4Shell: OpenJDK flaw allows remote code execution on AVX-512 CPUs

CVE-2026-114938 is a heap overflow in HotSpot's Base64 decoder intrinsic, affecting OpenJDK 17.0.6 and newer (incl. 21, 25, 27) on x86-64 chips with AVX-512 VBMI, such as AMD Zen 4 and newer and Intel Xeon from Ice Lake. Researchers showed RCE against Keycloak, Jenkins, Jira and others in default setups. Oracle and OpenJDK patched on 17 November; until you can update, start the JVM with -XX:-UseBASE64Intrinsics. Relevant for homelab hosts running Java services on recent AMD hardware.
